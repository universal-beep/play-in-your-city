# Мой город — play in your city

Прототип аркадной игры в духе старых GTA (вид сверху) на **настоящей карте любого города**.
Выбираете свой город и едете по реальным улицам: выполняете заказы у реальных кафе и магазинов
или просто катаетесь, хоть за город.

**Играть:** https://universal-beep.github.io/play-in-your-city/

## Что есть

- Любой город: Тверь, Москва, Петербург, поиск по названию или «где я».
- Своя игровая карта: объёмные дома, парки, вода, дороги с бордюрами и разметкой, подписи
  улиц и заведений — всё рисуется в браузере из данных OpenStreetMap.
- Ездить можно только по дорогам: дома — стены. Машина «примагничена» к своей улице и полосе.
- Трафик: машины держат полосу, стоят на красный, пропускают пешеходов. Пешеходы ходят
  по тротуарам и переходят по «зебрам».
- Светофоры и одностороннее движение из OpenStreetMap. Проезд на красный, встречка или наезд
  на пешехода — штраф и звёзды розыска, на трёх звёздах за вами едет полиция.
- Маршрут к цели по улицам, как GPS в GTA: соблюдает одностороннее движение и предпочитает
  большие дороги.
- Режим «С заказами»: такси, доставка на время, погоня, партнёрский заказ (демо рекламы события).
- Режим «Просто покататься»: клик по карте ставит точку назначения. Город подгружается по ходу езды.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD | куда ехать по карте (вниз = вниз по экрану) |
| Удерживать стрелку | свернуть на ближайшем перекрёстке в эту сторону (жёлтая метка) |
| X | задний ход |
| Пробел | ручник |
| C | классическое управление (газ / тормоз / руль) |
| T | включить / выключить трафик |
| + / − или колёсико | масштаб |
| Клик по карте | точка назначения (Del — убрать) |
| M / Esc | меню заказов / закрыть |

На телефоне — кнопки на экране.

## Запуск у себя

Двойной клик по `Запустить игру.bat` (нужен Python): поднимется локальный сервер
на `http://localhost:8773/` и откроется браузер. Сборка не нужна — вся игра в одном `index.html`.

## Данные

- Дороги, дома, парки, названия улиц и заведения — © [участники OpenStreetMap](https://www.openstreetmap.org/copyright),
  векторные тайлы [OpenFreeMap](https://openfreemap.org).
- Светофоры — OpenStreetMap через Overpass API.

Это прототип: звука нет, партнёрские заказы — заглушки.
